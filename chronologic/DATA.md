# The benchmark file

Chronologic-EN-1.0 is one JSONL file: 866 lines, one question each. This document
describes every field. Counts below are from the released file, so they double as a
description of the benchmark's shape.

The public sample (`booksample/chronologic_en_1.0_sample.jsonl`, 100 questions) uses the
identical schema, so code written against it works against the full file unchanged.

## Required fields

Present on all 866 questions.

| Field | Type | Meaning |
|---|---|---|
| `question_number` | int | Stable identifier. Cited in the paper and used as the key in every scoring artifact. |
| `main_question` | str | What the model is asked. For cloze questions this includes the passage with the masked span marked. |
| `metadata_frame` | str | The context the answer should come from. Prepended to the question at scoring time. |
| `frame_type` | str | How specific that context is — see below. |
| `reasoning_type` | str | The task type, one of eight. |
| `question_category` | str | Finer-grained pipeline category; 18 values. `reasoning_type` is the grouping the paper reports. |
| `question_process` | str | How the question was made: `automatic` (515), `manual` (321), `poetry` (30). |
| `answer_strings` | list[str] | Candidate answers. Index 0 is always a ground truth. |
| `answer_probabilities` | list[float] | Admissibility of each, parallel to `answer_strings`. |
| `answer_types` | list[str] | Provenance of each, parallel to `answer_strings`. |
| `answer_length` | str | Expected length: `sentence_plus` (542), `short_answer` (172), `phrase` (152). Used as a generation cue and to select the style-scoring path. |
| `partial_credit` | int | 1 if scored by Bradley-Terry (346 questions), 0 if pass/fail (520). |
| `source_htid` | str | Identifier of the source text. |
| `source_title`, `source_author`, `source_date`, `source_genre` | str / int | Bibliographic description of the source. |
| `author_nationality`, `author_profession` | str | Author description; either may be empty where unknown. |
| `author_birth` | int or null | Null where unknown. |

## Optional fields

| Field | On | Meaning |
|---|---|---|
| `reject_reasons` | 346 | Per-option rubric for the Bradley-Terry judge, parallel to `answer_strings`; index 0 is `""`. Present exactly when `partial_credit == 1`. |
| `substantive_metadata_frame` | 691 | A trimmed frame used for substantive judging, where the full frame would give the answer away. |
| `manual_comment` | 349 | Editor's note on the question. Not used in scoring. |
| `added_answers` | 215 | Provenance records for later-added distractors: which model proposed each, and who approved it. |
| `period_words_in_main_question` | 386 | Count of period-specific vocabulary in the question, from an audit of how far questions use modern phrasing. |

## The parallel answer arrays

`answer_strings`, `answer_probabilities`, `answer_types` — and `reject_reasons` when
present — are always the same length. Questions carry 4 to 8 options:

```
 4 options:  87 questions        7 options:  49
 5 options: 366                  8 options:  19
 6 options: 345
```

### `answer_probabilities`

Not a binary flag. 1.0 marks a ground truth and 0.0 a plain distractor, but editors
assigned intermediate values to distractors that are partly defensible in the given
context — 0.5 is the commonest, with a long tail from 0.1 to 0.95. Treat this as a
graded admissibility score, not a label.

**86 questions have two ground truths.** These are the questions where the benchmark
measures a range rather than a point: either two passages from one source, or the views of
two members of a group the frame names. They are what makes the Bradley-Terry calibration
possible, since a held-out ground truth can be scored as though it were a candidate.

### `answer_types`

Where each option came from. The suffix is not always a model name — two families carry a
**year** instead, and are authentic prose displaced in time rather than anything
synthetic. Across the file's 4,743 options:

| Value | N | % | Meaning |
|---|---:|---:|---|
| `anachronistic_<model>` | 1042 | 22.0 | Generated by a named model, given the frame |
| `ground_truth` | 952 | 20.1 | From the source text |
| `manual` | 807 | 17.0 | Written by an editor |
| `same_book` | 782 | 16.5 | Another passage from the same source |
| `anachronistic_manual` | 283 | 6.0 | An anachronism written by an editor |
| `anachronistic_metadataless_<model>` | 279 | 5.9 | Generated *without* the frame, so it reads as generically modern |
| `negation` | 212 | 4.5 | Ground truth logically inverted |
| `same_character` | 110 | 2.3 | Dialogue by the same character elsewhere in the work |
| `other_book_<year>` | 87 | 1.8 | Authentic prose from a different book of that year (1875–1995) |
| `manual_negation` | 80 | 1.7 | Editor-written inversion |
| `anachronistic_<year>` | 63 | 1.3 | Authentic prose from the wrong period (1647–2025) |
| `manual_anachronistic_<model>` | 46 | 1.0 | Editor's replacement for a model-generated anachronism |

Two distinctions matter when interpreting results.

A `same_book` distractor is not wrong about the *context*, only about the question, so a
judge that accepts it is making a different error from one that accepts an anachronism —
which is why judge reliability is measured per distractor type rather than in aggregate.

The `<year>`-suffixed families are the hardest distractors stylistically, because nothing
about the prose is synthetic: only its date is wrong. A model that scores well on style
while failing these is tracking "does this read as period writing" rather than "does this
read as writing from *this* period."

Model slugs are recorded verbatim, including `distort1_` / `distort2_` prefixes for
deliberately degraded variants, so it is always visible when a model would be scored
against a distractor it generated itself.

## `reasoning_type`

The eight task types, with their counts — this is the paper's Table 1.

| Type | N | Task |
|---|---:|---|
| `sentence_cloze` | 160 | Restore a masked sentence, chosen so restoration requires inference |
| `constrained_generation` | 158 | Write a passage fitting a subject and a social context, sometimes with formal constraints |
| `phrase_cloze` | 155 | Restore a masked clause |
| `character_modeling` | 115 | Supply dialogue for a described character in a described situation |
| `knowledge` | 94 | Supply a fact or definition available at the time |
| `inference` | 78 | Draw a conclusion from given information — mathematics, grammar, rhetoric, engineering, poetic form |
| `abstention` | 62 | Decline a question that could not be answered at the time |
| `topic_sentence` | 44 | Supply a paragraph's missing topic sentence |

For the three groups the results tables report — cloze, generation, knowledge — see
`results/README.md`.

## `frame_type`

How much context the frame fixes.

| Value | N | Meaning |
|---|---:|---|
| `passage_context` | 316 | The question quotes a passage; the frame situates it |
| `book_context` | 314 | The frame describes a specific work and its author's position |
| `world_context` | 236 | Only date and nationality, for questions where a period's shared knowledge is what's being tested |

`world_context` is used where a question had one answer regardless of viewpoint; the other
two where the answer depends on who is speaking.

## Invariants

Verified against the released file:

- `partial_credit == 1` **iff** `reject_reasons` is present.
- `reject_reasons` is the same length as `answer_strings`, with `""` at index 0.
- `answer_strings[0]` always has probability 1.0.
- `question_number` is unique.

A note for anyone reading old code or notes: earlier drafts used a `context_judged` flag
where `partial_credit` now sits, and routed questions differently. The released file has
no `context_judged` field.
